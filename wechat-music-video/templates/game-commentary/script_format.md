# 解说词文件格式（input/script.txt）

一行一句解说词。两种可选标记，都可省略：

- `[mm:ss]` 或 `[f帧号]` 前缀：锁定该句配音的开始时间（相对广告底片）。
- `{gameplay:文件名}` 后缀：该句期间角落画中画播放哪段游玩片段；`{gameplay:off}` 表示收起画中画。

```text
# 井号开头是注释，不会被朗读
[00:02] 这段宣传片吹得有多神，我们实际玩玩看 {gameplay:clip01.mp4}
注意看这个技能特效，宣传片里是这样的
[00:14] 但实机里长这样 {gameplay:clip02.mp4}
[f620] 结论放最后，先看这段Boss战 {gameplay:off}
```

规则：

1. 未标时间的句子：接在上一句结束后，间隔默认 0.5s（`template.yaml → tts.gap_s` 可调）。
2. 时间标记冲突（上一句还没读完就到了下一句的锁定时间）：agent 列出冲突清单请用户裁定（提前上一句 / 顺延本句），不得擅自删句或加速。
3. 该文件是用户产物，agent 只读不改；切句、时间分配等派生数据写入 `planning/`，原文件保持原样。
