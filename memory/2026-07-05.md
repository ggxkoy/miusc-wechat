## 22:57 修复飞书 API 调用报错

**问题：** 在 zsh 中用 `$(...)` 嵌套执行 python3 + curl 时频繁语法解析失败，导致用户看到大量报错。

**根因：** zsh 的命令替换里嵌套引号、反引号容易出错。

**修复：** 创建了三个封装脚本，以后直接调用不再手写 inline python+curl：
- `bin/feishu_token.sh` — 获取 tenant_access_token
- `bin/feishu_read_bitable.sh` — 读取多维表格记录
- `bin/feishu_upload_bitable.sh <path> <name> <type> <feedback>` — 上传视频并创建记录

**教训：** 复杂的 python3 -c + curl 嵌套操作应该封装成独立脚本，不要在 shell inline 里写。
