# 模板说明：游戏解说（game-commentary）

## 模板定位

与 sigma-cowboy（固定参考视频、时间轴移植）不同，本模板是**结构型模板**：底片素材（游戏广告视频）每期都换，模板固化的是"广告底片 + 角落实机画中画 + 中文解说配音 + 同步字幕"这套结构和参数。

```text
一条游戏广告视频（链接或文件，每期输入）
  + 用户自己的游玩片段（角落画中画）
  + 用户提供的中文解说词（一字不改）
  → TTS 配音（音色经用户挑选）
  → 解说字幕与语音逐句同步
  → 广告原声在解说时自动压低（闪避）
  → 成片
```

## 每期输入

| 输入 | 形式 | 说明 |
|---|---|---|
| 广告视频 | 链接（yt-dlp 抓取）或本地文件 | 底片；遇登录墙/风控暂停请用户手动提供 |
| 游玩片段 | `input/gameplay/*.mp4` 若干条 | 用户实机录屏，角落画中画用 |
| 解说词 | `input/script.txt` | 用户提供，**一字不改**；格式见 `script_format.md` |

版权闸门：广告素材的使用授权必须在 P0 由用户确认（自有推广素材 / 官方授权 / 二创评论用途）；未确认前只能出内部样片，不得进入交付成片。

本模板专属依赖（在工作流第 3 节通用环境之外）：

- `yt-dlp`（广告链接下载，`pip install -U yt-dlp`；平台改版后需升级）。
- `edge-tts` 或所选 TTS 引擎（配音，见下方选型表）。

## 画面结构

```text
┌─────────────────────┐
│                     │
│   广告视频（底片）    │
│                     │
│              ┌────┐ │
│              │实机│ │  ← 游玩片段画中画（角落，位置/大小/圆角/
│              └────┘ │     "实机画面"角标均为参数）
│   ┌─────────────┐   │
│   │ 解说字幕     │   │  ← 与配音逐句同步，避开画中画区域
│   └─────────────┘   │
└─────────────────────┘
```

- 母版画幅跟随广告底片（横屏广告出横屏母版，竖屏出竖屏），渠道适配阶段再变换。
- 画中画默认右下角、宽度约为画面 28%，何时出现由解说词里的 `{gameplay:}` 标记或时间轴决定，不强制全程挂角。
- 字幕逐句渲染（不是整段悬挂），出现时刻 = 该句配音起点，消失 = 配音结束 +0.3s。

## 解说词与配音规则

1. 解说词原文一字不改：不改写、不润色、不缩写；仅允许按标点切句用于 TTS 和字幕。切句结果在 P1 报告中列出供确认。
2. TTS 先选音色再批量：agent 用默认引擎生成 2～3 个候选音色的同一句小样（试听句取解说词第一句），用户选定后才批量生成全文。
3. 逐句生成、逐句可重做：某一句发音/断句不对，只重生成该句，不动其他句。
4. 语音与字幕严格同步：每句字幕的入出点即该句音频的入出点，误差 ≤ 0.2s。
5. 混音：解说词出现时广告原声压低（默认 -12dB 闪避），解说间隙恢复；成片响度 -14 LUFS。

## TTS 引擎选型

| 引擎 | 定位 | 说明 |
|---|---|---|
| MiniMax TTS API（M3 推荐主力） | 高音质、同生态 | 执行代理是 MiniMax M3 时同源最顺，免额外接引擎；中文表现力强，支持声音克隆，需 API key |
| edge-tts（免费兜底） | 免费、CLI、零部署 | 微软神经语音，中文音色多（如 zh-CN-YunxiNeural 男声 / zh-CN-XiaoxiaoNeural 女声），`pip install edge-tts` 即用；跑通链路首选 |
| ElevenLabs | video-use 原生 | 整合 video-use 引擎时的原生 TTS，音质高、需 API key |
| CosyVoice / GPT-SoVITS | 克隆自己的声音（本地） | 开源本地部署，用户想用本人音色又不想走云 API 时启用，需 GPU |

选择顺序：免费跑通用 edge-tts；执行代理是 M3 时用 MiniMax TTS 作主力；接入 video-use 引擎或已有 key 时用 ElevenLabs。引擎与音色都是 `template.yaml → tts` 参数。

## 验收要点（母版）

- [ ] 解说词一字未改（成片字幕逐句与 script.txt 比对）。
- [ ] 每句字幕与配音同步误差 ≤ 0.2s。
- [ ] 画中画不遮挡广告关键信息（版号/品牌/UI 演示区），也不与字幕重叠。
- [ ] 闪避生效：解说时听得清人声，间隙广告原声自然回升。
- [ ] 游玩片段确为用户素材，出现时机与解说内容对应。
- [ ] 广告素材授权已确认。
